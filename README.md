# Ring Generator

Arranges people in a cycle. Each person is assigned to the next, and the last person closes the loop. Peer feedback and gift exchange are the usual cases; anything that needs a rotation of pairs works the same way. Pairs that already happened are skipped.

The search is SWI-Prolog, compiled to WebAssembly.

```sh
npm install
npm run dev
npm run build
```
