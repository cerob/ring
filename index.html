Ring Generator

Use it for peer feedback, gift exchange, or any other time you need to assign people to each other in a cycle.

Scientifically, this is a "directed Hamiltonian cycle generator in a complete graph with no self-loops and no repeated edges".

Technically, this is implemented in SWI-Prolog and can run in browser with WebAssembly. Prolog's declarative backtracking search finds valid rings without imperative loops or complex state management. What would be dozens of lines in JavaScript is a few elegant clauses in Prolog.

One name per line or comma-separated. Names converted to lowercase, because words starting in uppercase are reserved for variables in Prolog.
